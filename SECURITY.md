# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Zenkord, please report it privately through GitHub's private vulnerability reporting: https://github.com/xeen28170-rgb/zenkord/security/advisories/new

Do **not** open a public issue for security vulnerabilities.

We will acknowledge your report within 48 hours and work on a fix as soon as possible. We ask that you give us reasonable time to address the issue before disclosing it publicly.

## What to include

- A clear description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any suggested fix (optional)

## Scope

- Zenkord desktop app, standalone builds, browser extension, and web builds
- Plugins distributed with Zenkord
- Build tooling and CI/CD pipelines

Out of scope: third-party plugins, Discord's own services, and upstream Vencord/Equicord code that has not been modified.
